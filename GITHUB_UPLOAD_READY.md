## 📤 Upload to GitHub

### Step 1: Initialize Git
```bash
cd snappic-v2
git init
```

### Step 2: Add Remote
```bash
git remote add origin https://github.com/YOUR_USERNAME/snappic-v2.git
```

### Step 3: Add All Files
```bash
git add .
```

### Step 4: First Commit
```bash
git commit -m "feat: initial commit - Snappic v2 backend with classrooms, campus rooms, and educational feed"
```

### Step 5: Push to GitHub
```bash
git branch -M main
git push -u origin main
```
